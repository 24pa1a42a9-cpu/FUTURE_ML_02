# Support Ticket Classification System

## Overview
This project automatically classifies IT support tickets into categories using NLP and Machine Learning.

## Dataset
IT Service Ticket Classification Dataset

## Techniques Used
- Text Preprocessing
- TF-IDF Vectorization
- Logistic Regression
- Naive Bayes

## Results
- Logistic Regression Accuracy: 85%

## Example

Input:
Need admin rights to install software

Output:
Administrative Rights
